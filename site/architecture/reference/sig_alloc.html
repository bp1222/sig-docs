sig_alloc_set_allocator

void sig_alloc_set_allocator(const sig_allocator_t * allocator)
ParameterType
allocatorconst sig_allocator_t *

Overrides the active allocator. Passing NULL restores the default chosen by sig_alloc_init(). Any function pointer in `allocator` may be NULL if that operation is not needed by the caller of this override (e.g. a test that only exercises sig_alloc()): a NULL pointer for any operation falls back to the libc implementation for that operation only, so sig_calloc/sig_realloc/sig_free (and their SIG_DEBUG counterparts) never dereference a NULL function pointer even if the override only sets `alloc`.

sig_alloc_stats

typedef struct {
    uint64_t allocs;
    uint64_t frees;
    uint64_t reallocs;
    uint64_t bytes_requested; /* cumulative, never decreases */
    uint64_t live_blocks;     /* allocs - frees */
    bool live_bytes_tracked;
    uint64_t live_bytes; /* 0 unless live_bytes_tracked */
} sig_alloc_stats;

Allocation counters, maintained (atomically) in every build. Counts only successful calls: sig_realloc(NULL, n) is an alloc, a realloc of an existing block is a realloc (the live block count is unchanged), and sig_free(NULL) is ignored. Counters restart at sig_alloc_init(). live_bytes needs per-block size tracking, which only a SIG_DEBUG build has: live_bytes_tracked says whether live_bytes is meaningful.
