sig_expr

typedef struct sig_expr sig_expr;

A small condition language evaluated against a sig_value. input % 2 == 0 input.reading.temp > 21.5 && input.status != "off" input.subvalue ~ "failure" input.items[0] >= 10 The one variable is `input`, the value being tested. Literals are integers, decimals, "double" or 'single' quoted strings (escapes \\ \" \' \n \t), and true / false. Operators, loosest binding first: || && == != < <= > >= ~ (a ~ b: string a contains string b) + - * / % ! - (unary) .key [n] ["key"] (postfix: map member, list element, map member) Integers and decimals mix freely (the operation is done in decimals if either side is one); integer arithmetic wraps; % is integers only. Strings compare by bytes. An expression that cannot be evaluated against a particular input -- a missing key, an index out of range, operands of the wrong type, division by zero -- has no value. "No value" spreads through an operator, except that a false operand of && (or a true operand of ||) decides the result whatever the other side is. sig_expr_eval_bool() reports it as SIG_ERR_TYPE_MISMATCH so a caller can tell "false" from "could not be decided". A compiled sig_expr is immutable; evaluating it allocates nothing and is safe from several threads at once.
