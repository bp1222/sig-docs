sig_log_level_t

typedef enum {
    SIG_LOG_TRACE = 0,
    SIG_LOG_DEBUG,
    SIG_LOG_INFO,
    SIG_LOG_WARN,
    SIG_LOG_ERROR,
    SIG_LOG_FATAL,
} sig_log_level_t;

sig_log_init

sig_status_t sig_log_init(FILE * fp, sig_log_level_t level)
ParameterType
fpFILE *
levelsig_log_level_t

fp may be NULL to disable output while still tracking level. PRECONDITION: sig_log_init must be called before spawning any thread that will log, and sig_log_shutdown must only be called after every logging thread has been joined. Concurrent init/shutdown with logging threads results in undefined behavior.

sig_log_level_from_string

sig_status_t sig_log_level_from_string(const char * name, sig_log_level_t * out)
ParameterType
nameconst char *
outsig_log_level_t *

Parses a level name ("trace" .. "fatal", case-insensitive) into *out. Returns SIG_ERR_INVALID_ARG (leaving *out untouched) for NULL or an unknown name.
