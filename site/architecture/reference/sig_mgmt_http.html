sig_mgmt_http.h

include/sig/mgmt/sig_mgmt_http.h

SIG_MGMT_HTTP_MODULE_NAME

#define SIG_MGMT_HTTP_MODULE_NAME "mgmt_http"

Serves the management API over HTTP: a glue module that routes every path ("/" prefix) of the shared HTTP server (sig_http_server.h) to the mgmt module, so the REST API lives at the root (/system, /services/...). Register, in this order: sig_http_server_module() (with the transport config: bind, port, cors_origin, timeout_ms), sig_mgmt_module(), then sig_mgmt_http_module(). Without either of the first two the runtime's start fails with SIG_ERR_NOT_FOUND. The glue takes no config (NULL or ""; anything else is SIG_ERR_INVALID_ARG). Read the bound port with sig_http_server_get_port().
