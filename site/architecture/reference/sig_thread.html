sig_mutex

typedef union {
    void *sig_align;
    unsigned char sig_opaque[64];
} sig_mutex;

Opaque buffers sized to hold the largest common pthread backing type with headroom; sig_thread_posix.c static_asserts this at compile time so a mismatch fails the build, not silently corrupts memory.

sig_rwlock

typedef struct {
    sig_mutex mtx;
    sig_condition cond;
    int readers;
    int writer_active;
    int writers_waiting;
} sig_rwlock;

Reader/writer lock built from sig_mutex + sig_condition so any port that provides those two gets it. Many readers or one writer; a waiting writer blocks new readers, so writers are not starved. Not recursive.

sig_condition_timedwait

sig_status_t sig_condition_timedwait(sig_condition * cond, sig_mutex * mtx, const struct timespec * abstime)
ParameterType
condsig_condition *
mtxsig_mutex *
abstimeconst struct timespec *

Waits on cond until either notified or *abstime (an absolute CLOCK_MONOTONIC deadline, e.g. from sig_time_now() plus an offset) is reached. Returns SIG_OK on either a real notify or a timeout -- callers distinguish "did my condition become true" by re-checking their own state after the call returns, exactly as with sig_condition_wait(). Returns SIG_ERR_PLATFORM only on a genuine underlying error.
