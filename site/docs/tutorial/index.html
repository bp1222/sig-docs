Make your first capsule

You will build a capsule called scale that multiplies each integer it receives by a configured factor, then wire it between a simulator and a logger and run the result. The finished code is in the repository: the capsule in capsules/scale/scale_capsule.c and the project in examples/first_capsule/.

You need CMake 3.14 or newer, a C11 compiler and pthreads, on Linux or macOS.

1. Build the host with the capsule

Section titled “1. Build the host with the capsule”

The SIG_CAPSULES option lists the capsules compiled into the host. Setting it replaces the default list, so name every capsule you need: the simulator produces values, scale changes them, and the logger prints them.

2. The capsule

Section titled “2. The capsule”

A capsule is a sig_capsule value: a name, tables of input and output terminals, and a table of the properties it accepts. scale has one property, factor, an integer that defaults to 2 and must be at least 1.

The input terminal’s handler runs on the service’s worker thread for each signal. It reads the incoming value, multiplies it by the property and sends the result on the output terminal. A value that is not an int, or whose product does not fit in an int, is dropped with a warning.

Finally the capsule itself ties the pieces together: one default input terminal wired to the handler, one default output terminal, and the property table.

Writing capsules covers terminals, properties, start and stop hooks and scheduled work in full.

3. Register it

Section titled “3. Register it”

The host only knows the capsules compiled into it. The repository already has scale registered; for a capsule of your own, do the same three things:

  1. Put it in capsules/<name>/<name>_capsule.c with a header that declares extern const sig_capsule <name>_capsule;. Here that is capsules/scale/scale_capsule.h.
  2. Add <name> to the SIG_CAPSULES list, as in step 1.

4. Wire it

Section titled “4. Wire it”

A project is a directory with a configurations/ folder and a services/ folder. Each configuration names a capsule type and sets its properties. The file name is the configuration name.
