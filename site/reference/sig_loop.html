sig_loop.h

include/sig/runtime/sig_loop.h

The event loop of a single-threaded host: file-descriptor watches, one-shot timers and a per-iteration "step" hook (the runtime's service step), all dispatched from one thread. It is built on sig_poller, so the same code runs over poll(), kqueue or epoll. Everything except sig_loop_wake() and sig_loop_stop() must be called on the thread that runs sig_loop_run() (or before it starts). Callbacks run on that thread and may freely add, change and remove watches and timers, including their own.

sig_loop_timer_fn

typedef void (*sig_loop_timer_fn)(void *ctx);

One-shot timer: cb runs once, no earlier than `deadline` (absolute CLOCK_MONOTONIC, as from sig_time_now()). The handle is valid until the callback is entered or sig_loop_timer_cancel() is called; a holder must forget it in the callback.

sig_loop_step_fn

typedef void (*sig_loop_step_fn)(void *ctx, bool *out_has_deadline, struct timespec *out_deadline);

The step hook runs at the top of every iteration and reports when it next needs to run (*out_has_deadline false: only when woken). The host points it at sig_runtime_step().

sig_loop_run

sig_status_t sig_loop_run(sig_loop * loop)
ParameterType
loopsig_loop *

Runs until sig_loop_stop(): step, fire due timers, sleep until the earliest of the step deadline and the next timer or fd event, dispatch, repeat. A stop requested before the loop starts makes it return at once.
